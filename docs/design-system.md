# Salamat — дизайн-система из прототипа

Источник: `Salamat AI Nutrition (standalone).html` (bundled-страница, 324 КБ).
Всё ниже извлечено из прототипа механически; ничего не додумано. Там, где в прототипе
значения нет, стоит пометка «нет в прототипе».

## Как прототип устроен

Файл — самораспаковывающийся бандл: `<script type="__bundler/manifest">` содержит JSON
`uuid → {mime, compressed, data}`, где `data` — base64(gzip). Внутри:

| Ресурс | Размер | Что это |
|---|---|---|
| `6d3f785c….js` | 69 150 Б | сам прототип (React + рантайм шаблонизатора) |
| `a1c9d73b….js` | 131 835 Б | react-dom 18.3.1 UMD |
| `2069036b….js` | 10 751 Б | react 18.3.1 UMD |
| `a0b02a60….js` | 364 Б | обёртка `IOSDevice` (рамка телефона) |
| 4 × `.woff2` | 6–20 КБ | Figtree Light / Light Italic, latin + latin-ext |

`<script type="__bundler/template">` — JSON-строка со всей разметкой (142 790 символов).
Разметка описывает 26 экранов, переключаемых флагами `<sc-if value="{{ scXxx }}">`.

Токены темы объявлены **один раз** в `<style>` внутри `<helmet>` как CSS-переменные на
`.salamat` (светлая) и `.salamat.dark` (тёмная). Всё остальное в прототипе — инлайновые
стили, ссылающиеся на эти переменные. Это и есть дизайн-система.

## Шрифт: что в прототипе и что берём

Прототип грузит **Figtree** (Google Fonts, Light/Light Italic, подмножества latin и
latin-ext) с откатом на `-apple-system, system-ui, sans-serif`.

Проверка четырёх `.woff2` из бандла через fontTools:

| Глиф | Figtree |
|---|---|
| Кириллица (А, я, ё, Ң, Ү, Ө) | **нет** |
| ₸ U+20B8 (тенге) | **нет** |
| ⃀ U+20C0 (сом) | **нет** |

В шрифте 136 и 222 кодпоинта — только базовая латиница. Значит, для русского интерфейса
Figtree непригоден в принципе: прототип на русском тексте сам бы падал на системный шрифт.

Проверка системных шрифтов:

| Шрифт | Кириллица | ₸ U+20B8 | ⃀ U+20C0 |
|---|---|---|---|
| SF Pro (`/System/Library/Fonts/SFNS.ttf`, 1653 кодпоинта) | да | да | нет |
| Roboto (из артефактов Flutter, 896 кодпоинтов) | да | нет | нет |
| Manrope (текущий шрифт приложения) | да | нет (в коде уже прописан фолбэк) | нет |

`U+20C0` не содержит ни один из проверенных шрифтов, включая текущий Manrope. Знак сома
добавлен в Unicode 8.0 (2015) и живёт в шрифтах символов (`NotoSansSymbols`), которые
подтягиваются платформенной цепочкой фолбэков. Поэтому вывод знака сома в любом случае
опирается на фолбэк ОС, а не на основную гарнитуру — и это уже так в текущем приложении.

**Решение — системный шрифт.** Обоснование в отчёте; коротко: Figtree физически не умеет
русский, а системный шрифт — это ровно то, чем прототип рисует любой нелатинский текст.

## Чего в прототипе нет

* Русского текста — ни строки; вся копия английская.
* Значений `font-weight` кроме 500 и 600.
* Явной сетки/шкалы отступов — только фактические значения (см. таблицу выше).
* Состояний `disabled` для кнопок.
* Спецификации статус-бара приложения (в прототипе он нарисован рамкой `IOSDevice`).
