# screens2 — этап переноса прототипа, снимки

Android-эмулятор `Medium_Phone_API_36` (Google Play x86_64, API 36, 1080×2400),
debug-сборка из рабочего дерева. Тёмная тема прототипа (`kAppSkin = protoDark`).

Снимки `00`–`03` сделаны на эмуляторе, загруженном **без камер**
(`-camera-back none -camera-front none`): только так достижимы состояние
«камера недоступна» и, через отладочную кнопку «Симулировать распознавание»,
шторка подтверждения. Синтетическая сцена обычного эмулятора — не еда, поэтому
реального уверенного распознавания на нём не бывает.

## Чего здесь нет

* **Боксы детекции поверх видоискателя** (`_DetectionLabel`) — код есть, но
  показать нечем: состояние живёт 700 мс между уверенным распознаванием и
  шторкой, а уверенного распознавания эмулятор не даёт.
* **«Фото кончились»** и **шторка лимита фото** — достижимы только когда
  суточная квота исчерпана, а квота инкрементируется в Supabase лишь после
  успешного скана. Писать в продовую таблицу ради снимка не стал.
* Экраны блоков 2.1 (настройки), 2.2 (карточка блюда), 3 (вода), 4 (поиск),
  5 (коуч, голос) — не реализованы на этом этапе, см. отчёт.
