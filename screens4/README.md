# screens4 — «Что приготовить»

Android-эмулятор `Medium_Phone_API_36` (1080×2400), debug-сборка, тёмная тема
(`kAppSkin = protoDark`).

## Важно про данные на снимках

Функция `suggest-meal` **не задеплоена** — Supabase CLI на машине нет. Чтобы
снять карточки, debug-сборка была направлена на локальную заглушку
(`--dart-define=SUPABASE_URL=http://10.0.2.2:8792`), которая проксирует всё в
реальный проект и отвечает сама только на `/functions/v1/suggest-meal`.

**Блюда на снимках — фикстура, написанная руками**, чтобы прогнать вёрстку по
всем трём вердиктам и по широким/узким диапазонам. Это **не вывод модели** и не
доказательство её качества. Проверялся клиент: разбор ответа, диапазоны,
вердикты, запись в дневник по середине.

Всё остальное на снимках настоящее: остаток дня считается из реального
дневника через Supabase, язык из настроек, запись приёма пищи уходит в базу.
